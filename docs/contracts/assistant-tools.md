| 来源 | 用途 | 时机 |

## 边界

- 页面顶部固定注明「工具在仓库里维护（git），此页只读」。**没有任何编辑 / 新增 / 删除入口。**
- 空态：提示仓库 `mino_nexus/prompts/assistant/tools/` 下没有启用的工具。
- 后端未就绪：「助手服务尚未就绪」+ 重试。
- `tool` 参数指向不存在的 id：抽屉内提示「没有找到这个工具」。

## 不做

- 卡片模板的多渠道预览（设计 §8.3 提到，后端尚无模板接口，本期不做）。
- 任何编辑能力。
