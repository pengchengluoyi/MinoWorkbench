# 行为契约 · 操作记录

**原始实现**：`MinoConsole/src/views/Audit/index.vue` 43 行 + `utils/auditLog.js` 40 行
**目标路由**：`/audit`
**排期**：阶段 0（作为契约方法和 DataTable 范式的试点）
**状态**：**已实现**

## 数据

| 来源 | 用途 | 时机 |
|---|---|---|
| `sessionStorage['mino.workbench.audit']` | 全部数据 | 进页读一次 |

**没有 Nexus 接口。** 这页记录的是本浏览器会话内发生的管理操作，由各管理页在写操作成功后调 `recordAudit(action, detail)` 写入。上限 200 条，超出丢最旧的。

> 原实现把 key 命名为 `mino.console.audit`，这里改为 `mino.workbench.audit`。**旧 key 不做迁移**——会话级数据，关掉浏览器就没了，没有迁移价值。

## 状态

| 状态 | 挂哪 | 说明 |
|---|---|---|
| `rows` | 组件内 | 进页快照，不自动刷新 |
| 列显隐 | `localStorage` | 由 `DataTable` 的 `viewId="admin.audit"` 管 |

## 交互

| 操作 | 前置条件 | 成功反馈 | 失败反馈 |
|---|---|---|---|
| 查看列表 | — | 时间倒序渲染 | — |
| 清空本会话 | 至少 1 条（否则按钮禁用） | 二次确认 → 清空 → toast「已清空」 | 无（纯本地写） |
| 调整列显隐 | — | 即时生效并持久化 | — |

## 边界

- **空态**：「本会话还没有操作记录」+ 说明何时会出现条目。原实现只给 `empty-text="暂无数据"`，没说清为什么空。
- 加载态：数据同步读取，无加载态。
- 无权限：整个 `/audit` 在 admin 门禁下，非 admin 到不了。
- 接口超时：不适用。
- 并发冲突：不适用（单浏览器会话）。
- 长列表：上限 200 条，不需要虚拟滚动。
- **超长文本**：`detail` 字段可能很长 → 列设 `ellipsis`，悬浮看全文。
- **sessionStorage 不可用**（隐私模式 / 配额满）：读写都包了 try/catch，降级为空列表，页面不报错。

## 不做

- 原实现用 `v-loading` 包了整个面板，但数据是同步读的，加载态永远一闪而过 → **不做**，没有意义。
- 不加「导出」「按操作类型筛选」 → 本期不做，200 条上限下筛选价值低。
- 不上报 Nexus → Nexus 侧没有这个接口，保持纯本地。
