# Scout 多机接入行为契约

## 数据

节点列表来自 `GET /runtime/nodes`，按账号过滤，沿用 15 秒轮询及更新任务的 2 秒轮询。安装命令来自 `POST /runtime/nodes/install-token`；服务端决定 Nexus 地址、发布地址和受支持的系统/架构。安装状态来自 `GET /runtime/nodes/installations/{install_id}`，弹窗打开时每 3 秒读取。命令及短期凭证仅存在组件内存；稍后查看只保存非凭证安装记录 ID。

## 状态

保持现有 URL 的 node/pane 选择及节点栏折叠偏好。安装弹窗、系统选择和复制反馈为临时态。列表加载、空列表、全部离线、列表错误均显示标题及添加节点入口。复制和接入状态分别展示；注册记录必须关联本次安装且节点在线才能显示接入成功。

## 交互

添加节点打开安装弹窗并获取独立短期凭证；每台新电脑重新生成。系统默认仅采用可识别的桌面浏览器平台，可手动选择 macOS、Windows 或 Linux；未知平台要求选择。系统切换使用同一份未消费的命令集合。复制仅提示已复制；拒绝剪贴板权限时保留可选文本。关闭弹窗可稍后返回，继续查看本次安装状态。过期或消费后禁用复制，提供重新生成。沿用现有节点管理与插件/日志交互。

## 边界

命令获取失败与列表读取失败独立，分别提供重试。没有目标系统安装包不显示可执行命令，CPU 架构由目标安装脚本严格匹配。安装状态读取失败保留命令并提供重试；已注册但离线不宣称接入成功。更换账号后的历史安装 ID 不可读取他人记录。局域网 mino.local 提示适用范围；跨网络应由服务端配置可达域名或 VPN。

## 不做

不探测浏览器所在机器是否安装 Scout；不扫描局域网或选择 IP；不在浏览器执行命令、启动进程、直连第三方发布服务。不把复制成功或任意新节点出现当成本次安装成功。

## 账号隔离

节点查询缓存键包含 uid。退出/切账号时取消在途请求，递增账号 epoch、清空缓存并重置页面临时态；迟到响应和旧连接消息不写入新账号。管理员的已归属节点仍按本人账号隔离；节点列表额外显示未归属节点以便认领。日志、设备、插件、安装结果和实时快照均由服务端验证 owner。请求体 user_id、旧 studio_id 或浏览器标识不能授权。

机器人状态绑定到当前节点的实际 instance_id，并分别校验当前用户的绑定。Scout 注册需 account_isolation_version=1，旧客户端提示升级且不消费安装码。首次确认插件归属时使用按服务地址和账号隔离的空存储，原电脑的历史无 owner 配置、IM 库和密钥不继承，旧文件保留原位；历史文件不再导致新插件停用。已有 owner 的配置继续使用原路径，账号/服务不匹配仍拒绝继承。不提供节点共享或转移；仅历史无归属节点可由管理员在 Workbench 显式认领。


## V4 宿主与 Desktop 状态

节点页展示 `host.os/arch` 和桌面就绪/阻塞原因，设备区区分 PC 桌面、Web 浏览器与移动设备；Windows/Linux 未开放执行时如实展示，不生成虚假跨 OS 桌面。可执行数量来自服务端 `executable`，不以 online 计数。

## V4 需求 1.3：节点设备列表

插件分类只在打开已上报的微信插件时自动读取微信登录状态；进入邮箱、工作项或其他分类不调用微信。空插件快照视为尚未就绪，等待下一次状态上报后开放保存，避免旧隔离插件或刚注册时的错误请求与弹窗。

`devices[]` 仅包含当前节点的实时设备：必须匹配 `node_id`，已提供的 `current_scout_id` 也必须匹配。移动设备需上报连接通道；当前上报的 Desktop/Web 槽保留权限或执行器阻塞原因。不通过首次归属、同账号或历史设备补回。离线节点无实时设备，计数为零；全局任务选择器的历史设备展示独立保留。节点总览、列表计数与可执行计数共用同一筛选规则，空态说明设备应连接到所选 Scout 的电脑。

macOS 权限不足时“处理权限”在当前页展示屏幕录制和辅助功能的系统设置步骤。Desktop 工具按当前 Scout 设备清单自动生成，无需额外配置目录。管理员可认领未归属历史节点到当前账号；已有归属节点不显示认领按钮。管理员额外可查看未归属节点；这些节点在认领前不提供命令/插件操作与任务执行，已归属节点继续按账号隔离。查询缓存带账号 ID。
