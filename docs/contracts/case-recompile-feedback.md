# 批量重新编译反馈

## 数据

沿用每条用例的 version-chain 与 compile-jobs 接口，先取得 expected_revision，再使用稳定的 client_request_id 提交。结果只表示提交回执及提交时的任务状态，不代表后台编译完成；实际状态仍由用例详情读取。

## 状态

保留跨页选择、提交中、全部提交成功、部分提交失败、全部提交失败及失败项重试状态。结果摘要、详情抽屉和失败筛选为当前账号、项目及应用内的临时态，不写入 URL 或业务数据。

## 交互

底部操作栏保留重新编译、配置并执行、删除和取消选择。提交期间显示已处理数量和提交进度，禁用冲突操作。提交后只显示紧凑摘要；用户主动打开抽屉查看逐条结果、筛选失败项或展开任务编号。失败项重试沿用既有身份与版本检查，不重复提交已取得回执的成功项。关闭摘要只隐藏当前回执，不取消后台任务，也不清除用例选择。

## 边界

没有选择或回执时不显示操作栏。取消选择后仍可查看已有回执；提交中不可关闭摘要。跨页选择须保留数量提示。长名称、错误及任务编号须换行；逐条结果在抽屉内滚动，不撑高列表。支持窄屏及深浅色主题。账号、项目或应用切换清除临时展示并中断本地请求。接口超时、版本缺失、回执不完整仍显示原有错误，只有用户操作才重试。

## 不做

不改变编译、执行、删除的接口与业务含义；不自动重试、不增加后台轮询，不将提交进度当作编译进度。不改变列表行内原文与解析预览，不删除原有能力。仅将原来的无样式逐条文本移至按需打开的详情抽屉。
