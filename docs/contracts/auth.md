# 行为契约 · 登录与注册

## 数据

`POST /auth/register` 只提交邮箱和密码，不发验证码。邮箱前后端校验格式并规范化，数据库唯一约束兜底。普通注册固定普通用户、`email_verified=false`，不影响登录。

`POST /auth/login`、`GET /auth/status` 沿用 token、会话刷新和 WebSocket 初始化；切换账号或退出时取消查询、清空缓存并断开旧实时连接。

## 状态

`/login` 与 `/register` 为未登录路由。注册成功返回登录页，用路由状态回填邮箱及原目标地址。密码不进入路由或持久存储。

## 交互

注册只有邮箱、密码、确认密码。密码至少 8 位，确认密码必须一致。成功后显示登录提示；字段错误在字段旁展示，网络错误在表单内展示。

## 边界

重复邮箱、空白与大小写规范化、格式错误、弱密码、密码不一致、网络异常及提交期间防重复操作均有明确反馈。登录不能因邮箱未验证而被阻止。

## 不做

不提供验证码、发邮件、倒计时、忘记密码、找回页面或管理员角色选择。
