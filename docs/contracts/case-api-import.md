# 用例接口导入交互约束

选择用例接口与读取节点后自动获取项目列表；选定来源项目并选择按会话读取后自动获取会话列表。常规流程不设置「读取项目列表」「读取会话列表」前置按钮；失败提供重试，空列表显示具体说明。刷新项目同时使旧会话列表与选择失效。

只有一个项目/会话时自动选中；多个候选时要求明确选择，不能默认读取第一项。切换节点或项目时下级选择失效；查询按服务、账号、当前项目、节点、来源项目隔离，取消浏览器旧请求并忽略迟到结果。已选节点消失时禁止静默换到另一节点。

列表加载使用局部状态，不锁住来源与上级选择。最终读取用例单独操作并防止重复点击；读取成功才进入字段核对，不自动解析或提交导入。其他操作不能让「恢复上次导入」显示加载动画。

服务地址来自 Nexus 集成配置，登录邮箱和密码来自当前 Scout 的当前环境。错误必须区分地址、凭据、登录失败、网络失败与空列表，不用「请连接服务」统称。

用例导入编译策略（正则兜底、预览并行、提交拦截默认值）在管理端「集成配置 → 用例导入编译」维护，与用例服务 API 同页保存。
