## 三、Scout 节点页

砍掉运行概览后，`/settings/runtime` 直接渲染 `ScoutNodesPage`（去掉 `embedded` prop），`RuntimeStatusPage.vue` 836 行整个删。

`ScoutNodesPage.vue` 1,599 行是 `electronAPI` 用得最重的页面（14 处）：

| 能力 | 可行性 | 方案 |
|---|---|---|
| 节点在线状态 / 版本 / 设备列表 | ✅ | Nexus 读，现已有 |
| **停止 / 重启 Scout** | ✅ 保留 | Nexus 经 `/node` 下发命令，Scout 自行执行 |
| **查看 Scout 日志** | ✅ 保留 | Scout 上报日志尾部 → Nexus → 前端；页面内查看器 + 下载 |
| 升级 Scout | ✅ 间接 | Nexus 下发目标版本，Scout 自己拉包重启 |
| Scout 配置 | ✅ 间接 | 配置存 Nexus，Scout 启动时拉取 |
| **冷启动（未运行时拉起）** | ❌ 做不到 | 进程没在跑 → `/node` 连接不存在 → 没有接收方。浏览器无法在远端机器拉起进程。**解法：设备侧装成常驻服务**，前端按钮语义变成"唤醒 / 重启" |
| 安装 Scout ・打开日志文件夹 ・设备投屏 ・页面录制器 | ❌ | 下线 |

### 跨产品依赖（阻塞节点页写功能）

| 产品 | 需新增 |
|---|---|
| **Nexus** | `/node` 下行命令通道（`stop`/`restart`/`upgrade`）、日志拉取接口、Scout 配置存取接口 |
| **Scout** | 接收并执行下行命令、上报日志尾部、支持自更新、**安装为设备侧常驻服务** |

> 本仓库不改这两个产品，也不启停它们。接口未就绪前，节点页先做只读看板，写操作留占位。
